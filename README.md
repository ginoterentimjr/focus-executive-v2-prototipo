# Focus Executive 2.0 · protótipo navegável

Protótipo da versão 2.0 do Focus Executive, que liga o OPS, a análise crítica e a superação.

O conteúdo é restrito. A página publicada traz apenas dados cifrados (AES-GCM, com chave derivada da senha por PBKDF2) e só abre com a senha de acesso. Nada é gravado: ao recarregar a página, a demonstração volta ao início.
